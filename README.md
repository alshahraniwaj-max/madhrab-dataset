# Madhrab Saudi Proverbs Dataset

An Arabic dataset developed for **Madhrab (مَضرِب)**, an AI-powered project designed to help children and teenagers understand Saudi proverbs in a simple and engaging way.

## Dataset Overview

The dataset contains **600 samples** covering **100 Saudi proverbs**, with **6 different samples for each proverb**.

Each sample is structured into three fields:

- **proverb**: The Saudi proverb.
- **instruction**: A question or instruction related to the proverb.
- **response**: The corresponding answer explaining the proverb according to the instruction.

## Dataset Structure

| Column | Description |
|---|---|
| `proverb` | Saudi proverb |
| `instruction` | User question or instruction |
| `response` | Expected response |

## Files

- `Madhrab_Saudi_Proverbs_Dataset.xlsx` — Excel version of the dataset.
- `Madhrab_Saudi_Proverbs_Dataset.json` — JSON version of the dataset.

## Purpose

The dataset was created to support the fine-tuning and evaluation of Arabic language models for understanding and explaining Saudi proverbs.

## Project

This dataset is part of **Madhrab (مَضرِب)**, developed for Arabthon 2026.
